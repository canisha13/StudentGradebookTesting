# StudentGradebookTesting

## Project Overview
This project demonstrates automated testing of a Student Gradebook application using Java, Maven, and TestNG.

## Technologies Used
- Java 17
- Maven
- TestNG
- Eclipse IDE
- Git & GitHub

## Project Structure
- src/main/java - Application source code
- src/test/java - Test classes
- test-output - Generated TestNG reports
- pom.xml - Maven configuration

## Test Cases
The project includes tests for:
- Adding students
- Adding grades
- Retrieving grades
- Validating grade ranges
- Multiple grades for the same subject

## Test Results
All tests executed successfully with passing results generated in the TestNG reports.
